# Latenode (latenode)

Latenode is an enterprise-grade low-code integration and AI automation platform with prebuilt SaaS integrations and native access to top-tier LLMs. It combines the ease of no-code tools with the flexibility of low-code development for building automated workflows. Latenode supports inbound webhooks and JavaScript-based custom logic within scenarios but does not currently publish a public OpenAPI specification for an external REST API.
